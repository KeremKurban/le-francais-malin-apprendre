# Data Schema — Le Français Malin

## Entity Relationship Overview

```
User ─────────┬──── LearningSession ──── UserResponse ──── ResponseError
              │                    └──── (via session_id)
              ├──── SkillLevel
              ├──── Weakness ──────────── Topic
              └──── ReviewRecommendation ─ Topic

Exercise ──── Topic
Exercise ──── UserResponse
ExperimentRun (standalone — links to MLflow)
```

### Weakness

Aggregated per user × topic. Updated after every evaluation.

| Field | Type | Notes |
|-------|------|-------|
| id | UUID PK | |
| user_id | UUID FK→User | |
| topic_id | UUID FK→Topic | unique with user_id |
| error_count | Integer | cumulative |
| severity | Enum(low,medium,high) | computed: ≤3=low, ≤7=medium, >7=high |
| error_type_counts | JSONB | {grammar: 5, vocabulary: 2, ...} |
| last_seen | DateTime(tz) | |
| created_at | DateTime(tz) | |

### SkillLevel

One row per user × skill. Updated via exponential moving average (α=0.3).

| Field | Type | Notes |
|-------|------|-------|
| id | UUID PK | |
| user_id | UUID FK→User | unique with skill |
| skill | Enum(grammar,vocabulary,writing,speaking,communication) | |
| estimated_level | Enum(A1..B2) | derived from score_history |
| confidence | Float | 0-1, grows with more data |
| score_history | Float | EMA of scores (0-100) |
| updated_at | DateTime(tz) | |

Level mapping: score ≥85→B2, ≥70→B1, ≥55→A2, <55→A1

### ReviewRecommendation

Top-5 practice suggestions, rebuilt after each evaluation.

| Field | Type | Notes |
|-------|------|-------|
| id | UUID PK | |
| user_id | UUID FK→User | |
| topic_id | UUID FK→Topic | |
| priority | Integer | 1 = highest |
| reason | Text | human-readable explanation |
| exercise_type | String | suggested exercise format |
| created_at | DateTime(tz) | |
| completed_at | DateTime(tz)? | null = pending |

### ExperimentRun

Mirrors MLflow data in PostgreSQL for cross-querying.

| Field | Type | Notes |
|-------|------|-------|
| id | UUID PK | |
| mlflow_run_id | String(100) | links to MLflow UI |
| experiment_name | String(200) | |
| prompt_version | String(50) | |
| model_name | String(100) | e.g. claude-sonnet-4-6 |
| eval_type | String(100) | e.g. response_evaluation |
| metrics | JSONB | {score, error_count, latency_ms, ...} |
| params | JSONB | {exam_type, level, exercise_type, ...} |
| created_at | DateTime(tz) | |

## Indexes

- `users.email` — unique, B-tree
- `experiment_runs.mlflow_run_id` — B-tree
- `weaknesses.(user_id, topic_id)` — unique constraint
- `skill_levels.(user_id, skill)` — unique constraint
